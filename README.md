# book-price-analysis
📚 Book Price Analysis — Data Exploration & Market Insights

This project explores book pricing data to uncover patterns, pricing drivers, and potential business insights using Python and data analysis techniques.

The goal is to demonstrate how raw data can be transformed into actionable insights using structured data cleaning, exploratory data analysis (EDA), and visualization.

🎯 Project Objective

The primary objectives of this analysis were:

Clean and preprocess raw book pricing data

Perform exploratory data analysis (EDA)

Identify pricing trends and distribution patterns

Detect potential correlations between features and price

Generate insights that could support pricing or inventory decisions

🛠️ Technologies Used

Python

Pandas – data manipulation

NumPy – numerical operations

Matplotlib / Seaborn – visualization

Jupyter Notebook – interactive analysis

📊 Key Analysis Performed
1️⃣ Data Cleaning

Handling missing values

Removing duplicates

Formatting numerical and categorical fields

Ensuring consistent data types

2️⃣ Exploratory Data Analysis

Price distribution analysis

Descriptive statistics (mean, median, variance)

Outlier detection

Category-level comparisons

3️⃣ Visualizations

Histograms of price distribution

Boxplots for category comparison

Correlation heatmaps

Feature-to-price relationship charts

📈 Example Insights

While results depend on the dataset used, the analysis highlights:

The overall distribution of book prices

Whether pricing clusters around specific ranges

The impact of categories or features on pricing

Detection of unusually high or low priced books (outliers)

These insights could support:

Pricing strategy optimization

Inventory planning

Market segmentation

Revenue forecasting
